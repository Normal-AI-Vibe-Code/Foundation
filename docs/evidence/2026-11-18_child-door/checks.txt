One door for every program the server starts (ADR-001 G13), 2026-11-18
=======================================================================

What changed
  apps/server/src/child.ts is the only server file that imports node:child_process. A caller asks
  childOptions({ extras, set }, opts) for its options; spawnChild / execFileChild / execFileText /
  execFileSyncChild refuse any other options object and always rebuild env from the allowlist
  (childenv.ts BASE) plus the named extras, plus values Foundation sets (a name that looks like a
  secret can't be set). An env put on the options afterwards is never used.

Per program (extras beyond BASE; cwd)
  T3 (t3host.ts)            CLAUDE_CONFIG_DIR, CLAUDE_CODE_GIT_BASH_PATH, CODEX_HOME; set T3CODE_HOME; cwd <data>/t3 (unchanged)
  taskkill (t3host.ts)      none; cwd unchanged
  t3 CLI (vision.ts)        none; cwd unchanged (server's)
  Kiri (machines.ts)        none; detached, cwd unchanged
  gh (github.ts)            GITHUB_TOKEN, GH_TOKEN, GH_HOST, GH_CONFIG_DIR, GH_ENTERPRISE_TOKEN
  plan sync (plan.ts)       the same five + FOUNDATION_GH; set FOUNDATION_PLAN_FILE
  claude --version (agent)  CLAUDE_CODE_ENV
  claude -p (agent)         CLAUDE_CODE_ENV; cwd work/agent (unchanged)
  REA jobs (jobs.ts)        none / CLAUDE_CODE_ENV; cwd work/jobs/<job> (unchanged)
  terminal (hostterm.ts)    none; set TERM=dumb (and PS1="" on macOS/Linux)
  git (changelog.ts)        none
  tar (flowform-import.ts)  none
